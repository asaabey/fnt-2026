In Fimbria teacher preparation, upload nephrology-lesson.json, preview it,
then start a session. Reveal each question after votes are submitted;
explanations and the correct answer are released on reveal. Advance to the

it has not been published to GitHub or uploaded to a running Fimbria instance.

SCHEMA SUMMARY
Draft-07 JSON Schema, schemaVersion exactly 1.
Root requires only: schemaVersion, id, title, steps.
Unknown properties are rejected at the root, step and option levels.

Root id: 1–100 characters. Title: 1–200 characters.
Steps: 1–100 ordered objects.

Slide object:
  id: non-empty string, maximum 100 characters
  type: exactly "slide"
  title: non-empty string, maximum 200 characters
  body: string, maximum 10,000 characters

Question object:
  id: non-empty string, maximum 100 characters
  type: exactly "question"
  prompt: non-empty string, maximum 2,000 characters
  options: 2–8 objects, each with id and text only
    id: non-empty string, maximum 100 characters
    text: non-empty string, maximum 1,000 characters
  correctOptionId: string referencing one of that question's option IDs
  explanation: string, maximum 10,000 characters

All listed fields are required for their respective object type.
The runtime additionally checks unique step IDs across the lesson, unique
option IDs within each question and correct-answer references. These semantic
checks are not all expressed by the published JSON Schema alone.

The API limits uploads to 256 KiB. All lesson strings render as plain text:
there is no image, Markdown, HTML, table or private-teacher-notes field in v1.
This lesson uses short plain-text paragraphs and real line breaks in slide
bodies. Source metadata is kept in these notes rather than unsupported keys.

SOURCE-TO-LESSON ADAPTATIONS
Main Q23 (main PDF p16): wording tightened to ask for the best typical
maintenance regimen among the listed options; corticosteroid use remains
individualised. Option order retained.

Main Q24 (main PDF p16): wording standardised, including "oral bioavailability"
for clarity. The same pharmacological distinctions and option order remain.

Bonus Q18 (bonus PDF p17): news framing removed. The vignette now explicitly
specifies symptomatic hypophosphataemia, oral-iron intolerance and absence
of an immediate allergic reaction. Option C was narrowed to an individually
assessed alternative preparation with monitoring. This avoids treating a
vague prior "reaction" as blanket permission to use another IV iron. The
mechanism is described as increased active FGF23 and renal phosphate loss;
the source spelling "iGFG23" was not carried into teaching text.

Bonus Q33 (bonus PDF p31): wording shortened without changing the tested
renal EPO mechanism or option order. The page-image link in the extraction
is unnecessary for this question and was not imported.

Bonus Q55 (bonus PDF p47): the case was shortened to clinical and laboratory
findings. The CT reference was removed because Fimbria v1 has no image
field; no CT interpretation or invented imaging finding was inserted.
"Renal impairment" replaces an unsupported inference of CKD chronicity
from a single eGFR result. The four diagnosis options are preserved.

Bonus Q56 (bonus PDF p48): substantive adaptation. The original has raised
white cells and platelets, splenomegaly and pruritus, as well as erythrocytosis;
its answer options do not cleanly explain the whole presentation. The
lesson instead specifies persistent isolated erythrocytosis, normal white
cells/platelets and no vitamin deficiency. Splenomegaly and the other
potentially conflicting findings were omitted. "Cannot explain" was changed
to "LEAST likely". The original four exposure categories and order remain.
The consolidation slide highlights the distinction from a multilineage
blood-count abnormality. This is not presented as an official answer to the
unmodified original stem.

VALIDATION
See validation-report.json for the exact result and lesson byte count.
Validation uses the actual Fimbria parseLesson function (Ajv plus semantic
checks), not just a JSON syntax check. An isolated in-memory instance of
Fimbria's Store walks every step, saves a vote on all six questions,
checks answers/explanations are absent before reveal, checks their correct
release and vote totals after reveal, and ends the session. No live class,
production data, app configuration or account was changed.
